Quick Start Guide

1

Register an Account

Create a new user by sending a POST request with your name, email, and a strong password.

POST /api/v1/auth/register { "name": "Your Name", "email": "you@example.com", "password": "SecurePass1" }
2

Copy Your Token

The response includes an access_token and a refresh_token. Copy the access token.

Response: { "access_token": "eyJhbG...", "refresh_token": "eyJhbG...", "token_type": "Bearer" }
3

Authorize in Swagger

Click the Authorize button below, paste your token, and click Authorize. All protected endpoints will now work.

Authorization: Bearer eyJhbG...
4

Send an Email

Use the POST /api/v1/email/send endpoint to send emails with HTML content via Dreamhost SMTP.

POST /api/v1/email/send { "name": "Jane Doe", "email": "recipient@example.com", "message": "<p>Hello!</p>" }

Security Notice

This API enforces OWASP Top 10 security guidelines including rate limiting (60 req/min), JWT token expiry (1 hour), bcrypt password hashing, input sanitization, and secure HTTP headers. Never share your tokens. Use HTTPS in production.
